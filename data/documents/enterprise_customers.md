# Enterprise Customer Portfolio & Deployment Directory

This directory provides a consolidated index of strategic Tier-1 enterprise customers utilizing CloudScale Systems platforms, their licensed products, cloud deployment topologies, and active contract tiers.

- **Cloud Infrastructure**: Dedicated AWS VPC deployment in us-east-1

- **Status & Focus**: Maintains rigorous compliance controls; air-gapped token validation.
