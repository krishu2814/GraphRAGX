# Security Architecture & Compliance Specifications

CloudScale Systems adheres to defense-in-depth security standards designed to protect sensitive enterprise telemetry, customer datasets, and authentication credentials.

## Compliance Frameworks

- **SOC2 Type II Certification**: Audited annually by Ernst & Young across Security, Availability, and Confidentiality trust service criteria. Continuous compliance telemetry is collected via **Product Atlas**.
- **ISO/IEC 27001:2022**: Comprehensive Information Security Management System (ISMS) covering all cloud environments.
- **HIPAA BAA Availability**: Available exclusively to **Enterprise Tier** customers utilizing dedicated VPC deployments.

## Cryptography & Key Management

- **Data in Transit**: Enforced TLS 1.3 encryption across all public ingress points via **Gateway Service** and internal mTLS via SPIFFE/SPIRE workload identities.
- **Data at Rest**: All databases and S3/Azure storage buckets are encrypted using AES-256-GCM.
- **Envelope Encryption**: Tenant data is protected by unique Data Encryption Keys (DEKs), which are enveloped by Key Encryption Keys (KEKs) managed in AWS KMS, Azure Key Vault, or HashiCorp Vault.

## Vulnerability Management & Incident Triage

Security incidents are triaged under the Sev1-Sev4 severity rubric. Automated audit logs generated by **Identity Service** and **Policy Engine** are immutably archived into WORM (Write Once, Read Many) cloud storage for 7 years.
